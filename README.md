# Amal R — Portfolio

A responsive portfolio site showcasing Amal's software, AI, computer vision, and hardware interests, projects, education, and experience.

## GitHub Pages

The workflow in `.github/workflows/deploy.yml` publishes the static site to GitHub Pages whenever changes are pushed to `main`. After creating the repository, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions** if it is not already enabled.

The expected project URL is `https://amal-05.github.io/amal-r-portfolio/`.
